# algo-trading-alpaca-agent


An Alpaca crypto paper-trading pipeline whose Python/HTML/test files are **generated by a
Claude Agent SDK multi-agent system** (`claude_codegen.py`): a Researcher reads the installed
alpaca-py source into a brief, a Coder writes each module and must pass an in-process
verification tool, the harness re-verifies deterministically and retries with feedback, and a
Tester triages pytest failures back to the responsible module.

Compared with the AG2/Gemini predecessor (`../TradingWithAlpaca` (the AG2/Gemini original)) the pipeline adds:

* **OMS** — order lifecycle: the front door for every order and algo intent, idempotent
  `client_order_id`, audit trail, consumer-group recovery, dead-letter stream, REST reconciliation,
  paper/live separation. Forwards execution to EMS; never calls Alpaca order endpoints itself.
* **EMS** — execution: the single Alpaca write path, publishing an execution report for every
  submit/cancel. OMS and EMS run in one `oms_ems` process.
* **Algo engine** — the strategy service: TWAP scheduling with restart-safe state, children routed
  through OMS. VWAP and Implementation Shortfall registered as stubs and shown disabled in the GUI.
* **Persister** — the only SQLite writer; drains the Redis streams into the history tables in
  batches, so no trading worker ever blocks on disk.
* **Fault tolerance** — supervisor with backoff, heartbeats, Redis retry + spill buffer, WAL SQLite,
  health endpoint and health strip in the UI.
* **Tests** — offline unit suite (fakeredis) and live integration suite that really connects to
  Alpaca paper + Redis, receives ticks, places and cancels an order and checks it landed in the
  stream and SQLite.

## Generate

```bash
pip install -r requirements.txt -r requirements-codegen.txt
export ANTHROPIC_API_KEY=sk-ant-...     # Anthropic Console key (required by the Agent SDK)
python claude_codegen.py                # missing stages + test gate
python claude_codegen.py --stage all    # regenerate everything
```

## Run (paper)

```bash
cp run.bash.example run.bash && $EDITOR run.bash && source run.bash
docker run -d -p 6379:6379 redis
scripts/run_all.sh                      # subscriber, trade_stream, oms_ems, algo_engine, persister, webgui -> http://127.0.0.1:5000
cd generated && python cli.py health && python cli.py twap BTC/USD buy 0.0002 --duration 60 --slices 2
python -m pytest -q generated/tests -m "not live"     # offline
python -m pytest -q generated/tests -m live           # needs creds + Redis + workers
```

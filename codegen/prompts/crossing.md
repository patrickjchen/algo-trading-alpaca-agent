You are generating: crossing.py — the CENTRAL LIQUIDITY BOOK / internal crossing service. It sits between OMS and
EMS: OMS forwards every `submit` / `cancel_order` to it on `alpaca:cross:requests`; it nets offsetting internal
interest (crosses) BEFORE anything is routed to the exchange, and routes only the residual to EMS. It is the ONLY
writer of `alpaca:ems:requests`. It never calls Alpaca order endpoints (read-only `trader.latest_quote` and
`trader.get_asset_rules` are fine), never touches SQLite, never writes the OMS order hashes (it publishes events
on `alpaca:trade_updates` and OMS/persister apply them). `import algos` only for `round_price`.

WHY: two orders on the same symbol and account with opposite sides whose prices cross (buy limit ≥ sell limit, market
crosses anything) can be matched internally at the midpoint: both legs avoid the exchange fee and each saves half the
spread. Flow today is mostly algo children and GUI/CLI orders from different books (portfolios).

CONFIG (env, read inside functions/body): `CROSS_ENABLED` (default "1"), `CROSS_HOLD_S` (default 1.0; resting limit
orders wait this long for a counterparty before being routed; per-order `hold_s` in the payload overrides),
`FEE_BPS` (default 25 — estimated exchange fee per side, for savings accounting), `CROSS_CONSUMER` (default `cross-1`).

LIVE STATE (keys from runtime: `book_key(symbol, side)`, `book_order_key(coid)`, `SET_RESTING`, `CROSS_STATS_KEY`,
`cross_stats_key(symbol)`, `internal_order_id(coid)`, `DEFAULT_BOOK`, `STATE_TTL_S`; values via `runtime.hset_state`)
- `alpaca:book:<SYM>:buy` / `:sell` ZSET: score = limit price (market buy → 1e12, market sell → 0), member = client_order_id.
- `alpaca:book:order:<coid>` HASH: `client_order_id, order_id (= internal_order_id(coid)), account, book, symbol, side, type, time_in_force, qty, remaining, crossed_qty, crossed_notional, limit_price, source, algo_id, slice_idx, status (resting|routed|filled|canceled|rejected), received_ts, route_at, routed_order_id, error`.
- `alpaca:book:resting` SET of coids currently resting (scanned by `tick`).
- Stats: HINCRBYFLOAT on `alpaca:cross:stats` and `alpaca:cross:stats:<SYM>`: `crosses, crossed_qty, crossed_notional, est_fee_saved, est_spread_saved, routed_orders, routed_qty, accepted_orders`.

FUNCTIONS (exact names)
- `as_order(h: dict) -> dict`: book hash → order dict for events/replies: `{id: order_id, client_order_id, symbol, side, type, time_in_force, qty, limit_price, filled_qty: crossed_qty, filled_avg_price: crossed_notional/crossed_qty or None, status: <mapped>, submitted_at: received_ts, updated_at: now, venue: "internal", book, routed_order_id, error}` where status maps `resting → accepted`, `filled → filled`, `routed → replaced`, `canceled → canceled`, `rejected → rejected`; and `partially_filled` when crossed_qty > 0 and status resting.
- `emit(r, event: str, h: dict, **extra)`: `runtime.publish(r, runtime.STREAM_TRADE_UPDATES, {event, execution_id: extra.get("execution_id"), order_id: h.order_id, client_order_id, symbol, side, price: extra.get("price"), qty: extra.get("qty"), position_qty: None, ts: now_iso, account, order: as_order(h), source, algo_id, slice_idx, venue: "internal", book, **extra})`. Events: `internal_accepted`, `internal_fill` (one per leg, `execution_id = f"x-{cross_id}-{side[0]}"`, `cross_id`, `counter_client_order_id`, `counter_book`, `price`, `qty`), `internal_routed` (after EMS ack; `routed_order_id`), `internal_rejected` (`error`), `internal_canceled`.
- `cross_price(buy: dict, sell: dict, quote: dict | None, rules=None) -> float | None`: both limit → `(buy_limit + sell_limit) / 2`; limit vs market → the limit; both market → `(bid+ask)/2` from the quote (None if no quote); round with `algos.round_price(px, rules.price_increment, side="buy")` when rules give an increment; must satisfy `sell_limit ≤ px ≤ buy_limit` for limit legs.
- `match(r, coid: str, quote: dict | None, rules=None) -> list[dict]`: the incoming order's hash `h`; candidates = opposite ZSET, best price first (for an incoming buy: sells with score ≤ buy limit (any for market) ascending; incoming sell: buys with score ≥ sell limit descending), time priority within equal price (`received_ts`). Skip: same coid, different `account`, `cross == "deny"` on either side, counterparties no longer resting. For each: `qty = min(h.remaining, c.remaining)`; `px = cross_price(...)` (None → skip); `cross_id = runtime.new_id()[:12]`; update BOTH hashes (`remaining -= qty`, `crossed_qty += qty`, `crossed_notional += qty*px`; remaining == 0 → status `filled`, ZREM + SREM resting, `hset_state(..., ttl=STATE_TTL_S)`); `emit(internal_fill)` for both legs; stats (`crosses +1`, `crossed_qty`, `crossed_notional`, `est_fee_saved += notional * FEE_BPS/1e4 * 2`, `est_spread_saved += (ask-bid) * qty` if quote has both sides else 0). Stop when `h.remaining == 0`. Return the list of cross dicts `{cross_id, symbol, price, qty, buy_coid, sell_coid, buy_book, sell_book, ts}` (also log one line each: `CROSS <SYM> qty=<q> px=<px> <buy_coid>(<book>) x <sell_coid>(<book>) saved≈$<fee+spread>`).
- `route(r, coid: str) -> dict`: `h` must be resting with remaining > 0; `rep = forward_to_ems(r, {kind:"submit", account, client_order_id: coid, symbol, side, type, qty: remaining, limit_price, tif, source, algo_id, slice_idx, book})`; acked/already_submitted → status `routed`, `routed_order_id = rep["order_id"]`, ZREM + SREM resting, EXPIRE, `emit(internal_routed, routed_order_id=…)`, stats `routed_orders +1`, `routed_qty += remaining`; rejected/error → status `rejected`, error, ZREM/SREM, EXPIRE, `emit(internal_rejected, error=…)`; `unknown`/`timeout` → status `routed` with `routed_order_id` None, `emit(internal_routed)` (OMS reconciliation resolves it). Return rep.
- `forward_to_ems(r, payload, timeout=10.0) -> dict`: `runtime.send_command(r, runtime.STREAM_EMS_REQUESTS, payload, timeout)` with a fresh `cmd_id` (thin wrapper for tests).
- `accept(r, p: dict) -> dict`: validate like EMS (side buy|sell, type market|limit, qty>0, limit needs limit_price>0, tif gtc|ioc default gtc, coid `^[A-Za-z0-9_-]{1,48}$`, account paper|live) → `{ok False, status:"rejected", error}`; if a book hash already exists for this coid → `{ok True, status:"already_submitted", order_id, client_order_id, order: as_order(h)}`. Create the hash (status resting, `book = p.get("book") or DEFAULT_BOOK`, `received_ts`, `route_at = now + hold_s` where `hold_s = float(p.get("hold_s", CROSS_HOLD_S))`, `cross = p.get("cross","allow")`); SADD resting; ZADD; stats `accepted_orders +1`; `emit(internal_accepted)`. Then, if crossing enabled and `cross != "deny"`: `quote = trader.latest_quote(symbol, r=r)` (exceptions → None), `rules = algos.rules_from_dict(trader.get_asset_rules(symbol, live, r=r))` (exceptions → None), `crosses = match(...)`. Then if `remaining > 0` and (`type == "market"` or `tif == "ioc"` or `hold_s <= 0`) → `rep = route(r, coid)` immediately (EMS down → leave resting, `route_at = now`, warn). Reply `{ok True, status:"acked", order_id: internal_order_id(coid), client_order_id, order: as_order(h), venue:"internal", crossed_qty, remaining, crosses: [cross_ids], routed_order_id}` — status `rejected` (ok False) only if an immediate route was rejected and nothing crossed.
- `cancel(r, p: dict) -> dict`: `coid = p.get("client_order_id")` or derived from an `order_id` starting with `int-`; `h` = book hash. resting → ZREM/SREM, status canceled, EXPIRE, `emit(internal_canceled)`, `{ok True, status:"cancel_requested", order_id}`; routed with routed_order_id → `forward_to_ems({kind:"cancel_order", account, order_id: routed_order_id, client_order_id: coid, source})` and relay; filled/canceled/rejected → `{ok False, status:"not_found", error:"order is <status>"}`; no hash but an external `order_id` given → forward `cancel_order` to EMS and relay; nothing → `not_found`.
- `handle_request(r, payload: dict) -> dict`: `cmd_id = payload["cmd_id"]`; `submit` → `accept`, `cancel_order` → `cancel`, else ok False; add `cmd_id`; `runtime.send_reply` when r given; return.
- `tick(r, now_ts: float | None = None) -> int`: for each coid in `SMEMBERS SET_RESTING`: hash missing → SREM; `route_at ≤ now` and remaining > 0 → `route` (only when `runtime.worker_alive(r, "ems")`; else warn once per 30 s); return routed count.
- `book_snapshot(r, symbol: str) -> dict`: `{symbol, bids: [{price, qty, book, client_order_id, age_s}], asks: [...]}` best-first from the ZSETs (pure read; webgui/cli call this logic themselves via Redis, but keep it here for tests).
- `process_requests(r, reader) -> int`; `body()`: `r = runtime.get_redis()`; `GroupReader(r, STREAM_CROSS_REQUESTS, "crossing", consumer, block_ms=100)`; loop: `process_requests`, `tick`; `time.sleep(0.02)` when idle. `main()`: `runtime.run_forever(body, "crossing")`; `if __name__ == "__main__": main()`.
Call `mcp__verify__verify_stage(stage="crossing")`.

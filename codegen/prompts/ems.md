You are generating: ems.py — the Execution Management System worker: the exchange GATEWAY and the ONLY process that
calls Alpaca order endpoints (through trader.py). It executes single orders on behalf of OMS and publishes an
EXECUTION REPORT for each. It contains NO algo logic (algo_engine.py) and NO SQLite (no `import sqlite3`).

FUNCTIONS (exact names)
- `publish_report(r, event: str, order: dict | None, *, account, client_order_id=None, order_id=None, symbol=None, side=None, qty=None, source=None, algo_id=None, slice_idx=None) -> None`: `runtime.publish(r, runtime.STREAM_TRADE_UPDATES, payload)` with payload `{event, execution_id: None, order_id, client_order_id, symbol, side, price: None, qty, position_qty: None, ts: runtime.now_iso(), account, order, source, algo_id, slice_idx}` (fill order_id/client_order_id/symbol/side/qty from `order` when not given). Never raises (log on failure).
- `execute_submit(r, p: dict) -> dict`: p = `{client_order_id, account, symbol, side, type, qty, limit_price, tif, source, algo_id?, slice_idx?}`. Validate (side buy|sell, type market|limit, qty>0, limit needs limit_price>0, tif gtc|ioc, client_order_id `^[A-Za-z0-9_-]{1,48}$`) → `{ok False, status:"rejected", error}`. `live = account == "live"`. `trader.submit_limit(symbol, qty, side, limit_price, client_order_id, live=live, tif=tif)` or `trader.submit_market(symbol, qty, side, client_order_id, live=live, tif=tif)`. Success → `order = trader._to_dict(result)` if needed, `publish_report(r, "ems_submitted", order, account=…, source=…, algo_id=…, slice_idx=…)`, return `{ok True, status:"acked", order_id, client_order_id, order}`. `APIError` with status 422 and 'client_order_id' in the message → `trader.get_order_by_client_id(coid, live)`; found → report + `{ok True, status:"already_submitted", order…}`; else `rejected` with the error text. Other `APIError` (4xx) → `rejected`. `trader.is_transient(exc)` (or RuntimeError-free network errors) → retry up to 3× (0.5/1/2 s); then look up by client_order_id; found → report + acked; else `{ok False, status:"unknown", error}`. Any other exception (including RuntimeError for missing creds) → `{ok False, status:"error", error: f"{type(e).__name__}: {e}"}`.
- `execute_cancel(r, p: dict) -> dict`: resolve `order_id`: given, else `r.get(runtime.coid_key(client_order_id))`, else `trader.get_order_by_client_id(coid, live)["id"]`; nothing → `{ok False, status:"not_found"}`. `trader.cancel(order_id, live)` → `publish_report(r, "ems_cancel_requested", None, account=…, order_id=…, client_order_id=…, source=…)`, `{ok True, status:"cancel_requested", order_id}`. APIError 404 / 422 (already terminal) → `not_found` with the message; transient → retry 3× then `error`; other → `error`.
- `handle_request(r, payload: dict) -> dict`: `cmd_id = payload.get("cmd_id") or payload.get("req_id")`; dispatch `submit` → `execute_submit`, `cancel_order` → `execute_cancel`, anything else → `{ok False, status:"error", error:"unknown kind"}`; add `cmd_id` to the reply; `runtime.send_reply(r, cmd_id, reply)` when r is not None; return it.
- `process_requests(r, reader) -> int`: batch read; per entry try → handle → ack; except → dead_letter + error reply.
- `body()`: `r = runtime.get_redis()`; `GroupReader(r, STREAM_EMS_REQUESTS, "ems", env EMS_CONSUMER default "ems-1", block_ms=500)`; loop `process_requests`; `time.sleep(0.02)` on empty batches. Log one line per execution: `submit coid=<…> <symbol> <side> qty=<qty> px=<limit_price> -> <status>`.
- `main()`: `runtime.run_forever(body, "ems")`; `if __name__ == "__main__": main()`.
Never touch `STREAM_OMS_COMMANDS`, `STREAM_ALGO_REQUESTS` or the order/algo hashes (OMS and algo_engine own them). Call `mcp__verify__verify_stage(stage="ems")`.

You are generating: oms.py — the Order Management System worker: FRONT DOOR for every order intent and owner of the
order LIFECYCLE. Live state lives in Redis; durable history is written by persister.py from the events OMS emits.
HARD RULES: no `import sqlite3`, no `runtime.sqlite_connect`; never call `trader.submit_*`, `trader.cancel*`
(execution belongs to ems.py). Read-only REST (`trader.open_orders`, `trader.list_orders`, `trader.get_order_by_client_id`) is allowed for reconciliation.

RESPONSIBILITIES
1. Consume `alpaca:oms:commands` (group `oms`, consumer env `OMS_CONSUMER` default `oms-1`): kinds `submit`, `cancel`, `algo_create`, `algo_cancel`. Validate → replay check → dedupe → forward (EMS or algo engine) → update live state → emit events → reply.
2. Consume `alpaca:trade_updates` (group `oms`, same consumer): exchange events and EMS execution reports → refresh the live order hashes.
3. Reconcile with Alpaca REST on startup and every `OMS_RECONCILE_S` (default 30) s; `SET alpaca:oms:last_reconcile <now_iso>`.
4. Heartbeat `alpaca:heartbeat:oms` (done by `run_forever`).

LIVE STATE (exact keys from runtime: `order_key`, `coid_key`, `cmd_key`, `SET_OPEN_ORDERS`, `STATE_TTL_S`)
- `apply_order(r, order: dict, *, account, source=None, algo_id=None, slice_idx=None, event_ts=None) -> dict`: `new = runtime.normalize_order(order)`; `old = r.hgetall(order_key(order_id))`; merge: `status = old.status if old.status in TERMINAL_STATUSES and new.status not in TERMINAL_STATUSES else new.status`; `filled_qty = max(old, new)`; `filled_avg_price/limit_price = new if not None else old`; `source/algo_id/slice_idx = old value if non-empty else given value, else derived from an `algo-<id12>-<idx>` client_order_id`; `account`, `last_event_ts`, `updated_at = now`. `runtime.hset_state(r, order_key, merged, ttl=STATE_TTL_S if terminal else None)`; `SET coid_key(coid) order_id` (EXPIRE STATE_TTL_S when terminal); `SADD/SREM SET_OPEN_ORDERS`. Return the merged dict (all values str → convert as needed for the reply). `changed(old, merged) -> bool` helper compares status/filled_qty/filled_avg_price/limit_price.
- `emit_order(r, merged: dict) -> None`: `runtime.publish(r, runtime.STREAM_OMS_EVENTS, {"type": "order", "ts": now_iso, "account", "source", "algo_id", "slice_idx", "order": merged})`.
- `emit_command(r, record: dict) -> None`: `publish(... {"type": "command", "ts", "command": record})` where record = `{cmd_id, kind, account, client_order_id, order_id, algo_id, slice_idx, source, payload, status, error, received_at, completed_at}`.
- `get_order_state(r, order_id=None, client_order_id=None) -> dict | None`: resolve via `coid_key` when needed; HGETALL → dict with numerics converted (`float`) or None.

COMMAND HANDLING
- `forward_to_ems(r, payload, timeout=10.0) -> dict` and `forward_to_algo(r, payload, timeout=10.0) -> dict`: `runtime.send_command(r, STREAM_EMS_REQUESTS / STREAM_ALGO_REQUESTS, payload, timeout)`; the forwarded payload gets a FRESH `cmd_id` (`runtime.new_id()`), never the caller's. Thin wrappers so tests can patch one name each.
- `handle_payload(r, stream_id: str, payload: dict) -> dict | None`: for trade_updates entries. If `payload["order"]` is a dict with an id → `apply_order(r, order, account=payload.get("account","paper"), source=payload.get("source"), algo_id=..., slice_idx=..., event_ts=payload.get("ts"))`; return the merged dict (None when no order). Do NOT emit an order event here (persister consumes trade_updates itself). Never raises on odd payloads (log + return None).
- `handle_command(r, payload: dict, stream_id: str | None = None) -> dict` (returns the reply and `runtime.send_reply(r, cmd_id, reply)`s it):
  * Prologue: `cmd_id = payload["cmd_id"]`; stored = `GET cmd_key(cmd_id)` → if present, re-send that reply and return it (replay). `received_at = now_iso`. `kind` must be one of the four; `account` in {paper, live} (default paper).
  * `submit`: validate side/type/qty>0 (limit needs limit_price>0), tif gtc|ioc (default gtc), `client_order_id` matches `^[A-Za-z0-9_-]{1,48}$`. Dedupe: `GET coid_key(coid)` → order hash exists → reply `already_submitted` (ok True) with that order; no forward. `runtime.worker_alive(r,"ems")` None → `{ok False, status:"error", error:"EMS not running"}`. Else `forward_to_ems({kind:"submit", account, client_order_id, symbol, side, type, qty, limit_price, tif, source, algo_id, slice_idx})`. Map: acked/already_submitted → `merged = apply_order(r, reply["order"], account, source=payload.source, algo_id, slice_idx)`; `emit_order`; rejected/error → keep error; `unknown` → status unknown (ok False; reconciliation finds it later by client_order_id); EMS `timeout` → status unknown, error "EMS did not reply".
  * `cancel`: resolve `order_id` via `get_order_state` (client_order_id → coid_key); nothing known and no order_id → `not_found`. EMS alive? else error. `forward_to_ems({kind:"cancel_order", account, order_id, client_order_id, source})`; on `cancel_requested` set the hash status to `pending_cancel` if currently non-terminal (hset) and `emit_order`.
  * `algo_create`: require `strategy` str, side, total_qty>0; `runtime.worker_alive(r,"algo_engine")` None → error "algo_engine not running"; `forward_to_algo({kind:"create", strategy, account, symbol, side, total_qty, duration_s, n_slices, limit_cap, params, source})`; relay `{ok, status, cmd_id, algo_id, algo, error}`.
  * `algo_cancel`: require algo_id; forward `{kind:"cancel", algo_id, source}`; relay.
  * Epilogue (always, even on exceptions → status `error`): build the command record (status = reply status, error, order_id/algo_id), `emit_command`, `SET cmd_key(cmd_id) json(reply) EX STATE_TTL_S`, `send_reply`. The reply carries the ORIGINAL cmd_id.
- `reconcile(r, accounts=("paper",), since_iso=None) -> int`: for each account, `trader.open_orders(live)` + `trader.list_orders("closed", after=since_iso or 24h ago, live)`; for each order: `old = HGETALL`; `merged = apply_order(...)`; if the hash was missing or `changed(old, merged)` → `emit_order`; count those. `SET alpaca:oms:last_reconcile now_iso()`. Catch APIError/transient/RuntimeError (no creds), log, return 0. Accounts: paper always; live only if env `OMS_RECONCILE_LIVE=1`.
- `process_updates(r, reader) -> int`, `process_commands(r, reader) -> int`: read a batch; per entry try → ack; except → `reader.dead_letter` (commands: also send an `error` reply so the caller never hangs).
- `body()` (sync): `r = runtime.get_redis()`; two `GroupReader`s (block_ms=500); `reconcile` at start; loop: process_commands, process_updates, reconcile when due; `time.sleep(0.05)` when both batches were empty.
- `main()`: `runtime.run_forever(body, "oms")`; `if __name__ == "__main__": main()`.
Call `mcp__verify__verify_stage(stage="oms")`.
